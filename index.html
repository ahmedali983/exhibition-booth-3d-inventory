What is in this repository?

This open catalogue combines two deliberately separate things: a functioning parametric booth engine that generates editable 3D geometry on demand, and a research index of third-party 3D models for booths, exhibition components, staging and CAD drawings.

What can I customize?

Width, depth, booth exposure, structural style, fit-out type, white/black base, accent colour and an optional brand sign. Your geometry is regenerated, rather than a screenshot being recoloured.

Exports

GLB is a binary glTF mesh that opens in Blender and most 3D viewers. OBJ is basic editable mesh geometry. DXF contains a dimensioned two-dimensional concept plan and is not a complete manufacturing package. JSON contains the exact input parameters. An independent Python asset generator is provided under scripts/ to prepare sample GLB and DXF files from the same parametric concept.

Third-party inventory

Images and models from creator websites, marketplaces and GitHub are not copied without an explicit compatible licence. Sketchfab's public search API can index model metadata, but downloadable files require an authenticated user session; its original creators and licences must remain attributed.

How to run

Use GitHub Pages (Settings → Pages → Deploy from branch → main / root) or run python -m http.server 8000 from the repository root. The viewer uses Three.js 0.164.1 from jsDelivr, so the first load requires an internet connection.
